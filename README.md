# Prashant Singh - National Powerlifter Portfolio

A responsive athlete portfolio website built with React, Tailwind CSS, Framer Motion, and React Router DOM.

## Features

- Responsive Design
- Athlete Profile
- Achievements Showcase
- Personal Records
- Gallery
- Instagram Integration
- Contact Section

## Tech Stack

- React
- React Router DOM
- Tailwind CSS
- Framer Motion
- React Icons

## Run Locally

npm install
npm run dev
